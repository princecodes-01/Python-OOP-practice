# Python OOP: Employee Class

## Description
This program demonstrates the use of a class and object in Python.

## Concepts Covered
- Class and object
- Class attributes
- Instance attributes
- Methods
- The `self` keyword

## Code Explanation
The `Employee` class has two class attributes: `language` and `salary`.

An object named `harry` is created. Its language is changed to `"English"`, while its salary remains `12000`.

## Output
```text
The language is English. The salary is 12000
```

## Technology
Python 3
